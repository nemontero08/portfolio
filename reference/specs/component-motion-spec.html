Component & Motion Specification

Second extraction pass on the Nico Montero portfolio — focused on component behavior and interaction, not foundations. Grounded in the compiled export CSS/HTML from index.html, how-i-work/index.html, vitalmed/index.html. Where the export doesn't expose a runtime (Framer Motion) value in static markup, it is marked runtime value not recoverable from export rather than guessed.

1. Component specifications

Button (Resume tile)

Anatomy

Container (tile) → label text + trailing arrow icon.

Variants

Tile (filled surface, used for Resume) · Inline (text link, used inside body copy — underline-free, color-only).

States

Default: bg-2, text-primary label, arrow static. Hover: bg lightens to bg-3, arrow nudges up-right. Focus/disabled: not present in export (no visible focus ring or disabled tile in source).

Responsive

No layout change across tiers — same tile proportions 375→1440; only the surrounding row wraps to full width below 768.

Layout

Inline-flex, gap 10px, padding ~14×20px, radius 12px.

Typography / Color

13px/500, text-primary on bg-2/bg-3.

LinkedIn Card

Anatomy

Container → LinkedIn mark (SVG) → label → decorative flourish path (drawn stroke, right-aligned).

Variants

Single variant, footer-only.

States

Default: flourish path invisible (stroke-dashoffset at full length). Hover: flourish draws itself in.

Responsive

No structural change; sits in the same footer row as Resume, stacks below 768 with it.

Layout

Flex row, gap 12px, padding 16px, radius 12px.

Typography / Color

13px/500 text-primary; icon and flourish inherit text-primary as stroke/fill.

Pill

Anatomy

Single text node in a rounded chip, no icon by default (NDA badge on Vitalmed adds a 🔒 emoji inline).

Variants

Default (50% black on dark card) · on-tint (used over case-study color washes, same recipe).

States

Static — no hover/active state observed; pills are informational, not interactive.

Responsive

Wraps via flex-wrap in tag groups below 768; no size change.

Layout

Inline-flex, padding 6×12px, radius 10px, gap 6px.

Typography / Color

10px/500, text-primary.

Section Eyebrow

Anatomy

Single uppercase label, no icon.

States

Static, non-interactive.

Responsive

No change across tiers.

Typography / Color

11px/600, text-faint, uppercase, ~0.06em tracking — the only tracked/uppercase text in the system.

Glass Card

Anatomy

Base surface — no header/footer chrome, just padded content; every other card composes on top of this.

Variants

Default (bg-2) · About/Lab variant with a background image instead of flat fill.

States

Static in most uses (Hero, About, What-I-Do tiles); interactive only where wrapped by a link (How-I-Work teaser, Case Study, Vitalmed meta cards are static).

Responsive

Grid reflows from multi-column (1440/1024) to single column below 768; padding stays constant (no responsive padding scale observed).

Layout

Radius 12px, shadow: 3-layer soft ambient + 1px inset "hairline" shadow (never adds to box width).

Case Study Card

Anatomy

Tinted container → (optional) "under construction" badge or eyebrow pill, top-right/left → title → tag pill row, bottom.

Variants

Live (linked, e.g. Vitalmed) · Coming-soon (Basalto, Lumine Gas — non-interactive, badge shown, no href).

States

Default: case-study color at ~60% opacity wash. Hover (live only): tint darkens/intensifies slightly, card lifts; cursor indicates link. Coming-soon cards show no hover change (not clickable).

Responsive

3-column grid at 1024/1440 → single column stack below 768; card min-height and tag wrapping adjust, title stays same weight/size.

Layout

Radius 20px, min-height ~220px, flex column justify-between, padding 20px.

Typography / Color

Title 19px/600 white; tags via Pill (10px/500); accent = the project's own brand hue, not the site accent.

Testimonial Card

Anatomy

Quote text → name → role, stacked.

States

Static content; only the slider container is interactive.

Responsive

Card width fixed (~280px) across tiers; how many are visible per viewport changes with container width, not the card itself.

Typography / Color

Quote 13px/400 text-primary; name 13px/600; role 10px/400 text-muted.

Testimonial Slider

Anatomy

Horizontal track of Testimonial Cards → pagination control (dot track + prev/next).

Navigation

Click dot → jump to that slide. Click prev/next → step ±1 with wraparound.

Transition

Exact easing/duration of the slide transition is runtime value not recoverable from export — the original uses Framer Motion's drag/swipe carousel; static markup only shows the resting state.

Drag

Original site supports drag/swipe on the track (Framer's default carousel behavior); exact velocity/threshold constants are not recoverable from export.

Responsive

Desktop shows multiple cards abreast with partial peek of the next card; narrow tiers (≤425) show one card at a time.

Anatomy

Index numeral → phase eyebrow → title → description, stacked in a card.

States

Static — no hover interaction observed on the step cards themselves.

Responsive

4-column grid at 1024/1440 → 2-column at 768 → 1-column below 425.

Typography / Color

Index 19px/700 text-faint; phase 11px/600 accent, uppercase; title 19px/600 text-primary; description 13px/400 text-muted.

How It Work Teaser

Anatomy

Title + subtitle block, left → circular outline arrow button, right.

States

Default: outline circle, transparent fill. Hover: circle fills solid accent, arrow color inverts to bg-0 for contrast.

Responsive

Row stays horizontal down to 425; circle size constant (48px) — the one element that doesn't shrink on mobile.

Back Link

Anatomy

Left-chevron icon + "Home" label, inline.

States

Default: text-muted. Hover: text-primary (simple color step, no icon motion detected).

Responsive

No change; always top-left of sub-page content.

Let's Talk Card

Anatomy

Accent-filled card → title "Let's talk" → click-to-copy email pill (Space Grotesk Bold).

States

Default: pill on translucent black-over-accent fill. Hover: no visible hover treatment change beyond the browser's default pointer cursor is present in static markup. Active/click: a "Copied!" confirmation string appears next to the email after click — this is the one component with genuine JS state (clipboard write), confirmed by its script wiring, not just CSS.

Responsive

Row wraps to stacked layout (title above pill) below 768.

Typography / Color

Title 19px/600 accent-deep on accent fill; email pill 13px bold Space Grotesk, accent-deep on ~8% black overlay.

5. Implementation guidance

Component boundaries

Match the inventory above 1:1 — one React component per row, no merging look-alikes (e.g. Pill stays generic and is reused by Case Study tags and the NDA badge, rather than forking a second "Badge" component).

Token structure

Keep the three-tier token model already in tokens/: raw values (hex/px) → semantic CSS custom properties (--bg-2, --text-muted) → component-level usage via var(). Do not flatten case-study accent colors into the shared palette — they're per-project, not system tokens.

CSS strategy

CSS Modules per component (already the pattern in portfolio-web/), values taken verbatim from Section 1 above rather than re-approximated. Reserve global globals.css for tokens + resets only.

Responsive strategy

Five explicit breakpoints (375/425/768/1024/1440) as max-width media queries per component's module, matching the matrix in Section 4 — not a generic 2-breakpoint mobile/desktop split.

Animation strategy

Since exact runtime timing isn't recoverable, implement hover/reveal motion with Motion for React (already a documented dependency) using the observable before/after states from Section 2, and pick timing/easing values that read as "restrained, no bounce" per the design system's existing motion principle — treat those as reasonable defaults, not extracted constants, and flag them for a visual diff pass against the live Framer site once one is available.

State management

Only two components need real state: Testimonial Slider (current index) and Let's Talk Card (copied flag + timeout). Everything else is stateless/presentational — no global store needed.
